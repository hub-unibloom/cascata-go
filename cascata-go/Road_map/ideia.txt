Os três tipos de MCP do Cascata são fundamentalmente diferentes


## MCP WORNER (Global)  (Admin/Owner)

poder total sobre o sistema igual woner no dashboard se o worner acessar via MCP estive ativo em '@SystemSettings.tsx#L571-583'(/home/cocorico/Documentos/proejetos/cascata go/frontend/pages/SystemSettings.tsx linha 571-583)


## MCP WORNER TENACY (SEMI-Global) (Tenant-level) (Admin/Owner)

poder total sobre um tenant específico, igual owner no dashboard se o worner acessar via MCP Estive ativo em '@ProjectIntelligence.tsx#L311-328'
porem ele só geenia o TENACY, não tem acesso ao WORNER GLOBAL nem como o woner global, ele é semi  global, limitao a atuaaa somente como owner dentro do tenant  


## MCP Consumer (final user-level)

É um client MCP que o tenant expõe pra aplicações dele
Quem conecta é o app mobile do usuário final, um agente de IA, um n8n, etc.
Acesso idêntico ao que o usuário final teria via API REST
Limitado ao schema do tenant, zero acesso a infra pura é literlmente apens um consumior, como se fose um passageio na uber ou cliente de um restaurante.


todos os 3 tipos de MCP são fundamentalmente diferentes porem todos tem limites já exisstentes por rotas existentes e fluxos de autenticação e autorização.
